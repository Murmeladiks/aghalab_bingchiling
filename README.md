
# Aghanim's Labyrinth 2: Per se

This repository contains the custom game **Aghanim's Labyrinth: Per se**, a modified version of Aghanim's Labyrinth.

## Known Bugs
- **Missing Dialogue for Aghanim**: The Aghanim character may not display dialogue or show a UI icon due to issues with incorrect game startup lines.
- **Minimap Container**: The Minimap is on the top left on the screen and not in its container.
- **HUD Icon Placement**: Incorrect icon placements in the HUD may occur, which can interfere with gameplay or visual clarity.
- **Missing Resources**: Several files, including sounds, particles, and images, fail to load, causing missing assets in the game.
